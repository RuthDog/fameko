# Arkitektur- och produktbeslut

Kort syfte: Samla viktiga beslut som ska vägleda produkt- och teknikval.

- Prognos före historik.
- Fameko är ett planeringsverktyg, inte ett bokföringssystem.
- Expand/collapse används istället för djup navigering.
- Enkel redigering prioriteras framför avancerade funktioner.
- Mobilversionen är lika viktig som desktop.
- Keep it simple är högsta designprincip.
- All funktionalitet ska minska användarens handpåläggning.
